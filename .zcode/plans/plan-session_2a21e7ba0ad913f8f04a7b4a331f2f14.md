# LoL 延时伪直播 — 总体实施计划（M1 今晚交付，M2-M4 客户端完整规划）

# M1（今晚）：夜间弹幕采集器
## 目标
今晚做出可双击挂机的定时弹幕采集器：10 点设置好 → 00:30 起轮询开播 → 凌晨 1 点瑞士轮开始后记录房间 6（真实 room_id 7734200，赛事官方间）全部弹幕 → 下播后等待重开（覆盖多场次/断流）→ 09:00 自动收尾产出 `data/20261025_room7734200.jsonl.gz` + `meta.json`。
## 技术选型
Python 3.12.8（已装）+ venv，清华镜像装 `aiohttp`、`brotli`；自研最小 WS 客户端（~250 行，只处理弹幕+SC），blivedm 作协议备选。
## 结构与设计
```
lol延时直播/danmaku-collector/
  collector.py  config.json  start.bat  requirements.txt  README.md  logs/  data/
```
- 状态机：等待定时(00:30)→轮询开播(get_info,带UA)→录制中(WS+流式写,每60s复核)→下播等重开→09:00或Ctrl+C收尾
- 协议：先取 buvid3 cookie 防风控；wss://broadcastlv.chat.bilibili.com/sub；30s心跳；brotli/zlib解压；DANMU_MSG + SUPER_CHAT_MESSAGE
- 断线重连指数退避 2s→60s，空档记入 meta.gap
- JSONL：`{ts:毫秒, un:用户名, t:文本, ty:dm|sc}`，30s flush；收尾 gzip + meta.json（起止/条数/重连/gap）
- 代码级 SetThreadExecutionState 防休眠
## 交付前验证
①venv+依赖 ②房间 6 现在正在直播（185万在线），跑 60 秒真实弹幕测试验证落盘 ③earliest_start 设为 2 分钟后跑通定时状态机全链路。

# M2（第2-3晚）：对齐工具 — 弹幕↔回放时间戳匹配（项目命门）
## 输入输出
输入：当天 jsonl.gz + 官方"完整场回放"BV号；输出：对齐元数据（写进 meta）。
## 三层对齐策略
1. **自动对齐**：拉取 BV 自带弹幕（dm/list.so 接口）→ 两条"每秒弹幕密度曲线"（BV弹幕轴 vs 自录弹幕轴）做滑动互相关，相关峰=偏移量，峰值锐度=置信度（一血/开团/局间休息的特征峰足以定位 ±几分钟内的剪辑偏移）
2. **校准页（你操作，每场2分钟）**：置信度低时打开本地网页，左播视频右弹幕密度图，拖 offset 滑杆对准标志事件；支持双锚点检测中段剪辑漂移（分段线性映射兜底断流/剪辑）；顺带人工确认局分界 G1/G2/…（密度低谷+爆发自动预检测）
3. **用户端零操作**：对齐参数随弹幕包发布
## BV 获取
B站搜索接口按"赛事名+完整场回放+对阵"检索官方账号，校准页支持手动粘贴 BV。

# M3（第3-4晚+周末）：伪直播客户端（服务端+网页）
## 形态
Python 单文件本地服务（双击运行 → localhost → 自动开浏览器）；和采集器同仓库独立目录，复用 aiohttp。
```
lol延时直播/danmaku-server/  server.py + web/(index.html, app.js, style.css)
```
## 后端 API（都很薄）
1. `/api/days` 可看日期列表（本地 data/ + GitHub Releases 远程索引）
2. `/api/match/:date` 场次元数据：对阵、BV、对齐参数、局分界
3. `/api/danmaku/:date` 弹幕包（本地有读本地，没有则从 GitHub Release 下载并缓存）
4. `/api/playurl` 服务端带 UA/Referer/可选用户cookie 调 B站 playurl 解析回放 m3u8，必要时本地反代加头
5. 托管前端静态页
视频流由用户各自直连 B站 CDN，不中转不落地。
## 前端（仿B站直播页，仿制不搬运素材）
- ArtPlayer + 官方弹幕插件 + hls.js；右侧弹幕滚动栏（SC高亮）；装饰性聊天框；弹幕密度限制+屏蔽词
- **伪直播模式**：打开时 `播放位置=当前时间-(开播+offset)`，1倍速锁进度条；**隐藏视频总时长**（时长剧透局数）
- **连播（默认）**：完整场回放单视频一条无标记时间轴；**分集（可选）**：按局分界切段显示 G1/G2 标签；提供"跳过局间休息"按钮
- 防剧透：不显示比分/结果/局数，场次列表只有"A vs B"
## 自测
用 M1 攒下的瑞士轮真实弹幕 + 当天官方回放实测对齐精度（先自动对齐看置信度，再人工核对一血/水晶时刻）。
